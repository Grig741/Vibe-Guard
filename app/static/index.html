FAQ

Questions, answered

Is it safe to paste my firebaseConfig?

Yes. That config is already public — it ships inside your app's JavaScript for anyone to read. VibeGuard uses it only for the scan and never stores the API key; only the project ID, the grade and findings are saved.

Will the scan change or break my data?

No. Read checks only read. Write checks create a single __vibeguard_probe__ entry and delete it immediately; the sign-up test creates a throwaway user and deletes it. Your real data is never touched.

Can I scan someone else's app?

Only with permission. VibeGuard is built for checking projects you own or are authorized to test.

What does the full report include?

Every hole found, what an attacker can do with it, the exact request that got through, and step-by-step fixes with security rules you can paste straight into the Firebase console. One purchase includes several full scans so you can re-check after fixing.

How do I pay?

On the website, buy a license key and paste it under your report. In Telegram, tap Unlock and pay with Stars — the key is sent to your chat automatically and works on the website too.

Do you support Supabase?

Firebase first. Supabase checks are on the roadmap.
